# 09 · Conhecimentos Específicos — TI

**70% da prova** (40 questões × 1,75 = 70 pontos). Os 13 blocos do Anexo V. Pra você é terreno conhecido — o foco é fixar comparações e macetes que a banca cobra.

## 1. Fundamentos, arquitetura e SI
- Arquitetura **von Neumann:** CPU (UC + ULA), memória, E/S, barramento. Hierarquia: registradores → cache → RAM → disco.
- **SI:** dado → informação → conhecimento. Tipos: SPT/TPS, SIG/MIS, SAD/DSS.

## 2. Lógica, estruturas de dados e POO
- **Pilha (LIFO)**, **Fila (FIFO)**, lista encadeada, árvore, hash.
- **POO — 4 pilares:** Abstração, Encapsulamento, Herança, Polimorfismo.
- Complexidade: busca binária O(log n), linear O(n), ordenação eficiente O(n log n).

## 3. Engenharia de software e ágil
- **Requisitos:** funcionais (o que faz) x não funcionais (desempenho, segurança).
- **Testes:** unitário → integração → sistema → aceitação; caixa-branca x caixa-preta.
- **Scrum:** PO (prioriza backlog), Scrum Master (remove impedimentos), Dev Team. Eventos: Sprint, Planning, Daily, Review, Retrospective.

## 4. Web e APIs REST
- HTML estrutura, CSS estiliza, JS comporta.
- **Métodos HTTP:** GET (ler), POST (criar), PUT (substituir), PATCH (parcial), DELETE.
- **Status:** 2xx sucesso, 3xx redirecionamento, 4xx erro do cliente (401 não autenticado, 403 proibido, 404 não encontrado), 5xx erro do servidor.

## 5. Banco de dados
- PK (única, não nula), FK (integridade referencial). Normalização 1FN/2FN/3FN.
- **SQL:** DDL (CREATE/ALTER/DROP), DML (SELECT/INSERT/UPDATE/DELETE), DCL (GRANT/REVOKE), TCL (COMMIT/ROLLBACK).
- **ACID:** Atomicidade, Consistência, Isolamento, Durabilidade.

## 6. Redes — OSI e TCP/IP
- OSI 7 camadas; TCP/IP 4. **TCP** confiável (handshake) x **UDP** rápido sem conexão.
- Portas: HTTP 80, HTTPS 443, DNS 53, SSH 22, FTP 21. IPv4 32 bits, IPv6 128 bits.

## 7. SO Windows e Linux
- Linux: permissões `rwx` (`chmod 755`), raiz `/`. Windows: NTFS, Active Directory, GPO.
- **Backup:** completo, incremental (só o que mudou desde o último) e diferencial (desde o último completo).

## 8. Segurança — ISO 27001/27002
- **CID:** Confidencialidade, Integridade, Disponibilidade.
- **27001** = requisitos do SGSI (certificável). **27002** = catálogo de controles/boas práticas.
- Criptografia simétrica (AES) x assimétrica (RSA); hash (SHA-256); certificado digital.

## 9. Governança de TI
- **PDTI** (obrigatório na Adm. Pública). **COBIT** = governança; **ITIL** = gestão de serviços; **PMBOK** = projetos.
- Governança dirige e monitora (EDM); gestão executa.

## 10. Versionamento, CI/CD, contêineres
- **Git:** commit, branch, merge, pull/push. **CI** integra e testa; **CD** automatiza deploy.
- **Docker:** empacota app + dependências (compartilha o kernel, mais leve que VM). **Kubernetes** orquestra.

## 11. BI e análise de dados
- **ETL** (Extract/Transform/Load) → Data Warehouse → dashboards. **OLTP** (transacional) x **OLAP** (analítico).

## 12. Contratação de TI — Lei 14.133/2021
- Nova Lei de Licitações. **Pregão** para bens/serviços comuns (preferência eletrônico). ETP e Termo de Referência no planejamento.

## 13. LGPD e LAI
- **LGPD (13.709/2018):** dado pessoal e sensível; bases legais; ANPD fiscaliza.
- **LAI (12.527/2011):** transparência é a regra; sigilo é exceção (reservada 5 / secreta 15 / ultrassecreta 25 anos).

> **FIXAÇÃO (macetes de prova)**
> 1. 401 = "quem é você?" / 403 = "sei quem é, mas não pode".
> 2. 27001 = requisitos (certifica) / 27002 = controles (boas práticas).
> 3. COBIT governa, ITIL opera serviços, PMBOK gerencia projetos.
> 4. LAI manda mostrar; LGPD manda proteger.
